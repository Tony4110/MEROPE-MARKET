Les licences de marché se transfèrent.

Un opérateur qui a bâti son marché — datasets, historique, revenus — peut céder sa licence à un autre opérateur. Ce n'est pas une carte à collectionner : c'est une position productrice de données, avec un historique vérifiable. L'architecture est prête dès la V1 ; le marché secondaire ouvre après les premières enchères.

Les règles

Période de détention

Standard 90 j · Prime 180 j · Ultra 180-365 j. On crée de la valeur avant de céder — pas de flip spéculatif.

Transfert validé

Chaque cession est approuvée par Dreamotion : le repreneur doit pouvoir opérer. Pas d'échange anonyme.

Frais de transaction

Dreamotion prélève une commission (ex. 5-10 %) sur chaque transfert. Le marché devient un actif renouvelable.

Important — ce que ce n'est pas. Une Market License est un droit d'opérer transférable (comme une franchise ou un nom de domaine), pas un produit financier ni un investissement. Merope affiche un track record (datasets, historique, revenus générés, qualité), jamais une promesse de rendement ou une « valeur d'investissement ». Tout transfert passe par la validation de Dreamotion. L'opérateur acquiert la licence, les droits commerciaux et l'historique du marché ; Dreamotion conserve la technologie, les capteurs, la marque, le graphe d'opportunités et les règles de la plateforme.
Ce qui se construit dès maintenant

Le modèle de données est posé en V1 — propriétaire, historique d'enchère, transferts, performance, réputation, éligibilité au transfert — pour que le marché secondaire puisse ouvrir sans reconstruire. En attendant, tout se passe sur le marché primaire.
